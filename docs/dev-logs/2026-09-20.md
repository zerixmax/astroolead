# Development Log - 2026-09-20

## Verzija: 0.5.7 (Desktop scroll-reveal & client script initialization fix)

### 🛠️ Odrađeni zadaci

- **Riješen problem nevidljivog sadržaja ispod Hero sekcije na desktopu:**
  - **Uzrok 1 (CSS):** U [src/styles/global.css](file:///home/z3r1x/Dokumenti/astroolead/src/styles/global.css), `@supports ((animation-timeline: view()) and (animation-range: entry))` definirao je animaciju s `backwards` fill-modeom (`animation: fade-in-up-scroll auto linear backwards;`). Čim bi element pri skrolanju prešao `entry 70%`, animacija bi završila i element bi se vratio na bazični `opacity: 0; transform: translateY(...)`. Uklonjen je nestabilni blok native scroll-timelinea u korist provjerenih i glatkih CSS tranzicija na desktopu (`opacity 0.8s`, `transform translateY(30px)`), dok je na mobilnim uređajima (< 768px) zadržan neposredni prikaz (`opacity: 1`).
  - **Uzrok 2 (JS / Layout):** U [src/layouts/Layout.astro](file:///home/z3r1x/Dokumenti/astroolead/src/layouts/Layout.astro), `initScrollReveal()` je imao preuranjeni `CSS.supports` prekid koji je onemogućavao rad `IntersectionObserver`-a na Chromium preglednicima. Također, registracija skripti se oslanjala isključivo na event `astro:page-load` (koji se u Astru okida isključivo ako je prisutan `<ClientRouter />`). Skripta je ažurirana tako da se sigurno pokreće i na standardnom učitavanju stranice (`DOMContentLoaded` / direktno ako je DOM spreman) i na `astro:page-load`.
  - **Klijentske komponente:** U [src/components/layout/Navbar.astro](file:///home/z3r1x/Dokumenti/astroolead/src/components/layout/Navbar.astro) i [src/components/ui/Slideshow.astro](file:///home/z3r1x/Dokumenti/astroolead/src/components/ui/Slideshow.astro) osigurana je ista dvostruka inicijalizacija (`DOMContentLoaded` + `astro:page-load`) za padajuće izbornike i lightbox funkcionalnost.
- **Verzioniranje projekta:** Povećana verzija na `0.5.6` u [package.json](file:///home/z3r1x/Dokumenti/astroolead/package.json), [src/data/version.json](file:///home/z3r1x/Dokumenti/astroolead/src/data/version.json) i [docs/site-structure.md](file:///home/z3r1x/Dokumenti/astroolead/docs/site-structure.md).
