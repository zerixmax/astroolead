## Verzija: 0.5.4 (Uklonjen root redirect + promjena kontakt emaila)

### 🛠️ Odrađeni zadaci

- **Uklonjen root redirect (`/` → `/hr/`):**
  - Prije: `src/pages/index.astro` (Astro.redirect) generirao je `<meta http-equiv="refresh" content="2;url=/hr/">` — **2s kašnjenja** + puni drugi page load pri svakom ulasku na domenu.
  - Sada: nova shared komponenta [src/components/Home.astro](file:///home/z3r1x/Dokumenti/astroolead/src/components/Home.astro) renderira HR početnu direktno na `/` (bez redirecta). `hr/index.astro`, `en/index.astro` i root `index.astro` koriste `<Home lang=... />`.
  - `astro.config.mjs`: `redirectToDefaultLocale: false` (Astro je auto-prioritizirao svoj i18n redirect nad custom stranicom) + sitemap `filter` isključuje `/` (canonical ostaje `/hr/`).
  - `SEO.astro`/`Layout.astro`: novi prop `canonicalPath` → root postavlja canonical na `https://oleadigitalis.eu/hr/` (bez duplicate-content penala).
  - Slideshow naslovi/opisi premješteni u i18n prevode (`sections.slideshow.*`).
- **Promjena kontakt emaila:** `ivo@oleadigitalis.eu` → `ivo@korcula.me` u [hr.json](file:///home/z3r1x/Dokumenti/astroolead/src/data/i18n/hr.json) i [en.json](file:///home/z3r1x/Dokumenti/astroolead/src/data/i18n/en.json).
- **Verzioniranje projekta:** `0.5.4` u [package.json](file:///home/z3r1x/Dokumenti/astroolead/package.json) i [src/data/version.json](file:///home/z3r1x/Dokumenti/astroolead/src/data/version.json).
